# LDAP 登录配置

在「系统设置」中打开 **注册与登录** 选项卡（路径：系统 → 系统设置 → 注册与登录，或访问 `/sys/settings?tab=register`），可启用 LDAP 登录，并配置与现有 LDAP/AD 目录服务对接，使用户使用目录账号密码登录 Certd。

## 配置项说明

| 配置项 | 说明 |
|--------|------|
| **启用 LDAP 登录** | 开启后，登录页将显示「LDAP 登录」选项卡。 |
| **LDAP 服务器地址** | 必填。LDAP 服务地址，如 `ldap://ldap.example.com:389` 或 `ldaps://ldap.example.com:636`。 |
| **绑定 DN** | 可选。若目录不允许匿名搜索，填写用于执行搜索的 DN（如 `cn=admin,dc=example,dc=com`）。 |
| **绑定密码** | 可选。与绑定 DN 对应的密码。 |
| **用户 Base DN** | 必填。用户条目所在的基准 DN，如 `ou=users,dc=example,dc=com`。 |
| **用户过滤条件** | 可选。用于根据登录名查找用户的 LDAP 过滤条件，默认 `(uid={{username}})`。 |

## 用户过滤条件占位符

过滤条件中可使用 `{{username}}` 作为占位符，提交登录时会被替换为用户输入的用户名（已做 LDAP 特殊字符转义）。

常见写法示例：

- `(uid={{username}})`：按 uid 属性匹配（默认）。
- `(sAMAccountName={{username}})`：适用于 Windows AD。
- `(mail={{username}})`：按邮箱匹配。

## 首次登录与本地用户

- 若 LDAP 认证成功且本地不存在对应用户，系统会自动创建本地用户（不保存 LDAP 密码），并完成登录。
- 若本地已存在对应用户（按 LDAP 返回的用户名/邮箱匹配），则直接使用该用户登录。

## 安全建议

- 绑定 DN 与绑定密码为敏感信息，仅保存在系统私有配置中，不会暴露到前端或公开接口。
- 建议使用 LDAPS（`ldaps://`）或在网络层面保证 LDAP 通信安全。
- 为绑定账号分配最小权限（仅能读取用户所在子树），避免使用域管理员账号。
